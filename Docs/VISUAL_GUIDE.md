## 🔧 Quick Customization Tips

### Change Primary Color:

1. Search: `#ffd700` in all files
2. Replace with your color (e.g., `#ff6b6b` for red theme)

### Change Font:

1. Update imports in `index.css`
2. Modify `font-family` in styled components
3. Logo: Update `NavbarNew.jsx` Logo component

### Add New Tab:

1. Create tab component (copy existing tab structure)
2. Add state: `const [activeTab, setActiveTab] = useState("overview")`
3. Add button in `TabNavigation`
4. Add render in `ContentSection`

### Modify Image Sizes:

```jsx
// In styled component:
const CharacterImage = styled.img`
  width: 100%;
  height: 320px; // <- Change this
  object-fit: cover;
`;
```
